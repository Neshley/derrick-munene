# DM ARRANGIA — Universal Yamaha Style Engine

The Style Creator now has a **Generate Pro Style** action that creates an original, performance-oriented arranger style from DM ARRANGIA's musical building blocks.

## Generation goals

- 4 distinct Main variations
- 4 one-bar fills
- Break
- 3 intros
- 3 endings
- Dedicated rhythm, bass, chord, pad and phrase parts
- Variation in density, velocity, syncopation and instrumentation
- Conservative MIDI/SFF export for broad Yamaha compatibility

The generator is intentionally deterministic and does not copy an external style file. Reference styles can be used as quality benchmarks, while generated musical material remains original.

## Yamaha conversion

The exporter targets the conservative MIDI-only Yamaha style subset and writes Yamaha style metadata/CASM around the accompaniment MIDI data. Hardware compatibility still requires testing on representative Yamaha generations before claiming universal compatibility.
